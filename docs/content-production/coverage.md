# Couverture du manuel — production du cours complet

Source : **Manuel Apprenant v2** (version du 20 octobre 2026, dossier « Manuel Niger »,
avec le titre « Exercice : Rendre l'atelier plus vert » et la correction « Le tableau
de décision »). La copie de `design_handoff_entrapprendre/` peut être plus ancienne.

Catalogue : 2 parties, 7 modules, 37 unités (recalculé depuis
`source/catalog.source.json`). Chaque unité du catalogue correspond à une unité du
manuel, dans le même ordre et sous le même titre (accents corrigés).

Règles de conversion communes (voir le handoff de production) :

- Texte simple, « tu », une idée par bloc ; exemples tirés du manuel (Ramatou,
  Moussa, Amadou, Fatoumata, Ibrahim, Zeinabou et Hamidou), présentés comme fictifs.
- Tableaux larges → explications verticales (`text`, `accordion`, `tabs`, `process`)
  puis questions `textarea`.
- Grilles d'auto-évaluation → `scale` « Oui / Pas encore » (ou « Souvent / Parfois /
  Rarement »), sans total ni note.
- Quiz vrai/faux → `flashcards` (affirmation au recto, réponse expliquée au verso),
  sans notation.
- Jeux de classe → courte description + réflexion personnelle ; l'application ne
  prétend pas faire jouer le jeu.
- Calculs de Ramatou → `process`/`text` avec chiffres vérifiés ; calcul de
  l'apprenant en `textarea` (pas de calcul automatique).
- Fin d'unité : `takeaway` « À retenir », puis `journal_formation`
  (retiens / réussi / difficile / prochain pas / ressenti).
- Pas d'audio ni d'image dans cette première version (décision du 21 octobre) ;
  scripts de narration à préparer séparément.

Statuts : `à faire` → `brouillon` → `relu (Carlo)` → `published`.
